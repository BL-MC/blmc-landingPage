## The Solution - The Blinky-Lite<sup>TM</sup> Toolbox 
What is so different about Blinky-Lite?  Well, it is in the way Blinky-Lite<sup>TM</sup> communicates. 
- Most other control platforms use polling, just like your child continually asking you "Are we there yet?" on a long trip. 
- Blinky-Lite<sup>TM</sup> uses <span style="color:cyan;">publish-subscribe</span> messaging, similar to listening to the radio and the station interrupts with "We interrupt this program for a special announcement."

With publish subscribe, three important things happen. 
- <span style="color:cyan;"><b>Connections are made from the inside to the outside.</b></span> As we have proved at CERN, this is a much more secure way to start a communication.
- <span style="color:cyan;"><b>Messaging must follow a disciplined format</b></span> leading to a secure full stack solution. No more python scripts running around like rats in a castle.
- <span style="color:cyan;"><b>Reliable edge computing becomes a reality.</b></span> With edge computing, you put your intelligence next to the device you want to control, giving you high performance with high reliability.

Check out the <a href="https://blinky-lite.org/">Blinky-Lite<sup>TM</sup></a> site for more details.
